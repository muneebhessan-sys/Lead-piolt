# LeadPilot

Local-first lead-intelligence platform. The lightweight local runtime uses React/Vite/TypeScript, Python/FastAPI, SQLite/Alembic, a persistent SQLite-backed job state machine, deterministic evidence-bound intelligence, and SSRF-protected website auditing.

It does not require Docker, PostgreSQL, Redis, Celery, Ollama, or a cloud AI service to start. It deliberately does not claim unavailable providers are connected and does not fabricate lead, AI, or sending results.

See [SETUP.md](SETUP.md) and [FINAL_SYSTEM_REPORT.md](FINAL_SYSTEM_REPORT.md).
